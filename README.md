 Project Title: Word Scramble Game
📌 Description
This is a fun and interactive Word Scramble Game where players have to guess the correct word from a scrambled set of letters. It helps improve vocabulary, spelling, and thinking speed. Built  JavaScript , this mini-game showcases skills in state management, user input handling, and basic game logic.

🚀 Features
🔤 Random word scrambling logic

⌛ Optional countdown timer for each round

🧠 Input box to guess the original word

✔️ Score tracking and replay option

🔁 New word after each correct or incorrect guess

📱 Responsive design for mobile and desktop

🛠️ Tech Stack
Frontend:  HTML / CSS / JavaScript

Logic: State and event handling

Deployment: Netlify
